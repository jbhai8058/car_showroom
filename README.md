# 🚗 LUXE Car Showroom - Premium Automotive Website

A high-end car showroom website featuring luxury vehicles with stunning animations and responsive design.

## 🌟 Features

- **GSAP-powered animations** for smooth transitions
- **Tailwind CSS** for utility-first responsive design
- **Interactive inventory system** with filtering
- **Video background hero section**
- **Mobile-friendly navigation**
- **Contact form** with validation
- **Testimonial slider**
- **Scroll-triggered animations**
